# 習慣トラッカー

Google Apps Script をバックエンドとした習慣トラッキングアプリです。  
Google ToDo「習慣トラッカー」リストと双方向に同期します。

---

## セットアップ手順

### 1. GASコードの配置

1. [Google Apps Script](https://script.google.com/) を開き、習慣データを保存しているスプレッドシートのコンテナバインドスクリプトを編集する
2. `gas_code.gs` の内容をすべてコピーして GAS エディタに貼り付けて保存する

### 2. appsscript.json に Tasks スコープを追加

Tasks REST API を使うために OAuth スコープを手動で追加します（「サービス」からの追加は不要です）。

1. GAS エディタ左上の歯車アイコン「プロジェクトの設定」をクリック
2. 「マニフェスト ファイルをエディタで表示する」にチェックを入れる
3. エディタのファイル一覧に `appsscript.json` が現れるのでクリック
4. 内容を以下に書き換えて保存（`timeZone` は既存の値を維持してください）

```json
{
  "timeZone": "Asia/Tokyo",
  "dependencies": {},
  "exceptionLogging": "STACKDRIVER",
  "runtimeVersion": "V8",
  "oauthScopes": [
    "https://www.googleapis.com/auth/spreadsheets",
    "https://www.googleapis.com/auth/script.external_request",
    "https://www.googleapis.com/auth/tasks"
  ]
}
```

5. GAS エディタで `createTodayTasks` 関数を選択して「▶ 実行」をクリック
6. 「承認が必要です」というダイアログが出たら「権限を確認」→ Google アカウントを選択 → 「許可」
   - 「このアプリは Google で確認されていません」と表示されたら「詳細」→「（プロジェクト名）に移動」をクリック

### 3. Script Properties に MAIN_USER_ID を設定

毎朝のタスク自動生成トリガーが使用するユーザーIDを設定します。

1. GAS エディタの「プロジェクトの設定」→「スクリプト プロパティ」
2. 「プロパティを追加」をクリック
3. プロパティ名: `MAIN_USER_ID`、値: アプリの「設定・ユーザーID」に表示されている自分のユーザーID

### 4. 時間トリガーの設定

毎朝4〜5時に習慣タスクを Google ToDo に自動生成します。

1. GAS エディタの左メニュー「トリガー」(時計アイコン) をクリック
2. 右下「トリガーを追加」をクリック
3. 以下の通り設定:

   | 項目 | 値 |
   |---|---|
   | 実行する関数 | `createTodayTasks` |
   | イベントのソース | 時間主導型 |
   | 時間ベースのトリガーのタイプ | 日タイマー |
   | 時刻 | 午前4時〜5時 |

4. 「保存」をクリック

### 5. ウェブアプリの再デプロイ

新しいコードを反映させるため再デプロイが必要です。

1. GAS エディタ右上「デプロイ」→「デプロイを管理」
2. 既存デプロイの鉛筆アイコン（編集）をクリック
3. バージョンを「新しいバージョン」にして「デプロイ」
4. 表示された URL が `index.html` の `GAS_API_URL` と同じであることを確認

> **注意**: 再デプロイ後も URL は変わりません。`index.html` の書き換えは不要です。

## 機能概要

### 毎朝の習慣タスク自動生成
- 毎日 午前4時〜5時に GAS が起動し、登録済みの全習慣を Google ToDo の「習慣トラッカー」リストに追加します
- タスク形式: `[アイコン] 習慣名`（例: `💪 筋トレ`）
- 当日のタスクが既に存在する場合は重複追加しません

### アプリ起動時の ToDo 完了状態の反映
- アプリ起動時に Google ToDo の完了済みタスクを取得し、未反映の習慣に当日の完了を自動記録します
- バックグラウンドで非同期実行されるため、起動を遅らせません

### チェック操作の Google ToDo への反映
- アプリでチェックON → Google ToDo の対応タスクを完了にします
- アプリでチェックOFF → Google ToDo の対応タスクを未完了に戻します
- UI反映はローカル優先（即時）、Google ToDo への書き込みは裏で実行されます
